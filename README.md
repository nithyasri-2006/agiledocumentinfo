# Sentinel – Fraud Detection System

Sentinel is a **digital banking fraud detection project** designed to simulate transactions and identify suspicious or fraudulent activities.  
This project demonstrates how fraud detection logic can be applied in a real-world banking scenario using a clean and structured approach.

---

## 🚀 Features

- 🔐 Fraud detection based on transaction rules  
- 🧪 Transaction simulation for testing  
- 📊 Clear and user-friendly interface  
- ⚡ Fast and lightweight setup  
- 🧠 Demonstrates real-world banking use cases
